Assistance applications

Pour toute question sur mes applications, écrivez à texnically@gmail.com. Précisez le nom et la version de l’app, le modèle de l’appareil, la version du système et le problème rencontré. L’assistance est disponible en français, anglais, russe, italien, ukrainien, kazakh et espagnol. N’envoyez aucun fichier privé, mot de passe ou code d’association.

Airelay

Connectez les appareils au même Wi-Fi, gardez Airelay ouvert et saisissez l’adresse affichée dans le navigateur. Entrez le code actuel à six chiffres. S’il expire, utilisez le nouveau ; après cinq erreurs, attendez une minute.

En cas d’échec, vérifiez l’autorisation Réseau local dans Réglages, l’adresse et la communication entre appareils sur le Wi-Fi. Les réseaux invités, VPN et pare-feu peuvent bloquer l’accès.

Chaque fichier peut atteindre 2 Gio, selon l’espace libre. Si l’aperçu est indisponible, téléchargez le fichier pour l’ouvrir dans une autre app. Ne transférez pas de données sensibles sur un réseau non fiable : HTTP n’est pas chiffré.

Politique de confidentialité — Airelay

Si vous contactez l’assistance par email, je reçois votre adresse, votre message et les pièces jointes que vous choisissez d’envoyer. Je les utilise pour vous répondre et conserve la correspondance utile aux besoins d’assistance ou aux obligations légales. Vous pouvez demander sa suppression par email, sous réserve de ces obligations. Évitez les informations sensibles.

Ce site n’utilise aucun outil d’analyse, publicité, script de suivi ou cookie ajouté par moi. Il est hébergé par GitHub Pages, qui peut traiter des données techniques de requête, dont les adresses IP, pour son fonctionnement et sa sécurité selon la déclaration de confidentialité de GitHub. Votre fournisseur de messagerie traite également les emails selon ses propres conditions.
