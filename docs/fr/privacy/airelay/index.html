Politique de confidentialité — Airelay

Airelay est proposée par Akhan Almagambetov. Contact : texnically@gmail.com. Date d’effet : 2026-11-15.

Airelay ne nécessite aucun compte. L’app ne contient ni publicité ni SDK d’analyse ; le développeur ne reçoit pas vos fichiers ni vos données d’utilisation par son intermédiaire.

Les fichiers et les informations de dossiers sont conservés dans Airelay sur votre appareil. Seuls les fichiers reçus dans son espace sont partagés, pas votre photothèque, les documents de fournisseurs externes dans Fichiers ni les données d’autres apps. Langue et thème restent sur l’appareil.

Lorsque le partage est actif, les navigateurs associés du réseau local peuvent envoyer, lister, consulter, télécharger et gérer les fichiers reçus. HTTP n’est pas chiffré. Utilisez un réseau de confiance. Le code limite l’accès, sans chiffrer les échanges. Un navigateur associé garde l’accès jusqu’à l’arrêt du partage.

Désactiver le partage, verrouiller l’appareil ou quitter l’app arrête le service. Les fichiers terminés restent jusqu’à leur suppression ou à celle de l’app. Les transferts incomplets sont supprimés ; les restes d’une fermeture imprévue sont nettoyés au prochain lancement. Les sauvegardes iOS peuvent contenir vos fichiers selon vos réglages.

Si vous partagez un fichier avec AirDrop ou une autre app, le service choisi le traite selon ses propres conditions.

Pour la confidentialité ou l’assistance : texnically@gmail.com. Cette politique sera mise à jour si les pratiques d’Airelay changent.

Si vous choisissez de laisser un pourboire ponctuel facultatif dans une version proposant cette fonction, Apple traite l’achat via l’App Store selon ses propres conditions et sa politique de confidentialité. Airelay vérifie les informations de transaction sur votre appareil pour confirmer le pourboire. L’app ne reçoit ni les coordonnées de votre carte bancaire ni le mot de passe de votre compte Apple. Les pourboires ne débloquent aucune fonction, ne se renouvellent pas automatiquement et ne sont pas nécessaires pour utiliser l’app.

Si vous contactez l’assistance par email, je reçois votre adresse, votre message et les pièces jointes que vous choisissez d’envoyer. Je les utilise pour vous répondre et conserve la correspondance utile aux besoins d’assistance ou aux obligations légales. Vous pouvez demander sa suppression par email, sous réserve de ces obligations. Évitez les informations sensibles.

Ce site n’utilise aucun outil d’analyse, publicité, script de suivi ou cookie ajouté par moi. Il est hébergé par GitHub Pages, qui peut traiter des données techniques de requête, dont les adresses IP, pour son fonctionnement et sa sécurité selon la déclaration de confidentialité de GitHub. Votre fournisseur de messagerie traite également les emails selon ses propres conditions.
