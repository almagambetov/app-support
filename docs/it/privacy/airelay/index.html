Informativa sulla privacy — Airelay

Airelay è fornita da Akhan Almagambetov. Contatto: texnically@gmail.com. Data di entrata in vigore: 2026-11-15.

Airelay non richiede un account. Non contiene pubblicità o SDK di analisi; lo sviluppatore non riceve i file trasferiti né i dati di utilizzo tramite l’app.

File e informazioni sulle cartelle restano in Airelay sul dispositivo. Sono condivisi solo i file ricevuti nello spazio dell’app, non la libreria fotografica, i documenti di fornitori esterni in File o i dati di altre app. Lingua e tema sono salvati sul dispositivo.

Con la condivisione attiva, i browser abbinati nella rete locale possono caricare, elencare, visualizzare, scaricare e gestire i file ricevuti. HTTP non è crittografato. Usa una rete affidabile. Il codice limita l’accesso, ma non cifra il traffico. Un browser abbinato mantiene l’accesso fino all’arresto della condivisione.

Disattivare la condivisione, bloccare il dispositivo o uscire dall’app interrompe il servizio. I file completati restano finché non li elimini o rimuovi l’app. I trasferimenti incompleti vengono scartati; eventuali residui dopo una chiusura improvvisa vengono rimossi al successivo avvio. I backup iOS possono includere i file secondo le impostazioni del dispositivo.

Se invii un file con AirDrop o un’altra app, il servizio scelto lo gestisce secondo le proprie condizioni.

Per privacy e assistenza: texnically@gmail.com. Questa informativa sarà aggiornata se cambiano le modalità di trattamento dei dati di Airelay.

Se scegli di lasciare una mancia facoltativa una tantum in una versione che offre questa funzione, Apple gestisce l’acquisto tramite App Store secondo le proprie condizioni e informativa sulla privacy. Airelay verifica le informazioni della transazione sul dispositivo per confermare la mancia. L’app non riceve i dati della carta di pagamento o la password dell’Apple Account. Le mance non sbloccano funzioni, non si rinnovano automaticamente e non sono necessarie per usare l’app.

Nelle versioni che la offrono, l’assistenza mensile è un abbonamento facoltativo con rinnovo automatico gestito da Apple. L’importo scelto viene addebitato ogni mese fino alla disdetta nelle impostazioni degli abbonamenti Apple. Airelay verifica sul dispositivo le informazioni confermate di abbonamento e rinnovo per mostrare piano attuale, data di rinnovo o scadenza e modifiche programmate; permette inoltre il ripristino tramite Apple. Abbonarsi, annullare o ripristinare non cambia l’accesso al trasferimento di file: tutte le funzioni restano gratuite. I pagamenti sono soggetti alle condizioni e all’informativa sulla privacy di Apple.

Se contatti l’assistenza via email, ricevo il tuo indirizzo, il messaggio e gli allegati che scegli di inviare. Li uso per rispondere e conservo la corrispondenza pertinente per esigenze di assistenza o obblighi legali. Puoi richiederne la cancellazione via email, fatti salvi tali obblighi. Evita informazioni sensibili.

Questo sito non usa strumenti di analisi, pubblicità, script di tracciamento o cookie impostati da me. È ospitato da GitHub Pages, che può trattare dati tecnici delle richieste, inclusi gli indirizzi IP, per funzionamento e sicurezza secondo l’informativa privacy di GitHub.
