Airelay

Құрылғыларды бір Wi-Fi желісіне қосып, Airelay қолданбасын ашық қалдырыңыз және көрсетілген мекенжайды браузерге енгізіңіз. Ағымдағы алты таңбалы кодты теріңіз. Мерзімі өтсе, жаңасын пайдаланыңыз; бес қате әрекеттен кейін бір минут күтіңіз.

Қосылмаса, параметрлердегі жергілікті желі рұқсатын, мекенжайды және Wi-Fi құрылғыларының өзара байланысын тексеріңіз. Қонақ желілері, VPN және брандмауэрлер байланысты бұғаттауы мүмкін.

Бос орын жеткілікті болса, файл 2 ГиБ-қа дейін болуы мүмкін. Алдын ала қарау қолжетімсіз болса, файлды жүктеп алып, басқа қолданбада ашыңыз. Сенімсіз желіде құпия деректерді жібермеңіз: HTTP шифрланбайды.
