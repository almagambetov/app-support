Поддержка приложений

По вопросам о любом моём приложении пишите на texnically@gmail.com. Укажите название и версию приложения, модель устройства, версию системы и описание проблемы. Поддержка доступна на русском, английском, итальянском, украинском, французском, казахском и испанском языках. Не отправляйте личные файлы, пароли и коды подключения.

Airelay

Подключите устройства к одной сети Wi-Fi, оставьте Airelay открытым и введите показанный адрес в браузере. Укажите текущий шестизначный код. Если он истёк, используйте новый; после пяти ошибок подождите минуту.

Если соединения нет, проверьте разрешение «Локальная сеть» в настройках, адрес и возможность связи устройств в Wi-Fi. Гостевые сети, VPN и межсетевые экраны могут блокировать подключение.

Файл может иметь размер до 2 ГиБ при наличии свободного места. Если просмотр недоступен, скачайте файл и откройте в другом приложении. Не передавайте конфиденциальные файлы в недоверенной сети: HTTP не зашифрован.

Политика конфиденциальности — Airelay

При обращении по электронной почте я получаю ваш адрес, сообщение и выбранные вами вложения. Они используются для ответа; необходимая переписка хранится для поддержки или выполнения правовых обязательств. Вы можете запросить удаление по электронной почте с учётом этих обязательств. Не включайте конфиденциальные сведения.

На этом сайте нет добавленных мной аналитики, рекламы, отслеживающих скриптов или файлов cookie. Сайт размещён на GitHub Pages; для работы и безопасности GitHub может обрабатывать технические данные запросов, включая IP-адреса, согласно своему заявлению о конфиденциальности. Почтовый провайдер также обрабатывает обращения по своим условиям.
