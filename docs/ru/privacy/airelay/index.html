Политика конфиденциальности — Airelay

Airelay предоставляет Akhan Almagambetov. Контакт: texnically@gmail.com. Дата вступления в силу: 2026-11-15.

Airelay не требует аккаунта. В приложении нет рекламы и SDK аналитики; разработчик не получает через приложение ваши файлы и данные об использовании.

Файлы и сведения о папках хранятся в Airelay на вашем устройстве. Доступны только файлы, полученные в хранилище приложения: не медиатека, внешние документы из «Файлов» и не данные других приложений. Язык и тема сохраняются на устройстве.

При включённом обмене подключённые браузеры локальной сети могут загружать, просматривать, скачивать и упорядочивать полученные файлы. HTTP не зашифрован. Используйте доверенную сеть. Код ограничивает доступ, но не шифрует передачу. Подключённый браузер сохраняет доступ до остановки обмена.

Выключение обмена, блокировка устройства или выход из приложения останавливают обмен. Готовые файлы хранятся до удаления вами или удаления приложения. Незавершённые загрузки удаляются; остатки после аварийного завершения очищаются при следующем запуске. Резервные копии iOS могут включать готовые файлы согласно настройкам устройства.

При отправке через AirDrop или другое приложение выбранный сервис обрабатывает файл по своим правилам.

Вопросы о конфиденциальности и поддержке: texnically@gmail.com. При изменении обработки данных в Airelay эта политика будет обновлена.

Если вы решите внести добровольный разовый платёж в версии с такой возможностью, Apple обработает покупку через App Store по своим условиям и политике конфиденциальности. Airelay проверяет сведения о транзакции на устройстве для подтверждения платежа. Приложение не получает данные вашей банковской карты и пароль Аккаунта Apple. Платежи не открывают функций, не повторяются автоматически и не обязательны для использования приложения.

При обращении по электронной почте я получаю ваш адрес, сообщение и выбранные вами вложения. Они используются для ответа; необходимая переписка хранится для поддержки или выполнения правовых обязательств. Вы можете запросить удаление по электронной почте с учётом этих обязательств. Не включайте конфиденциальные сведения.

На этом сайте нет добавленных мной аналитики, рекламы, отслеживающих скриптов или файлов cookie. Сайт размещён на GitHub Pages; для работы и безопасности GitHub может обрабатывать технические данные запросов, включая IP-адреса, согласно своему заявлению о конфиденциальности. Почтовый провайдер также обрабатывает обращения по своим условиям.
