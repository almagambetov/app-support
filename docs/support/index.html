App support

For help with any of my apps, email texnically@gmail.com. Include the app name, app version, device model, system version, and a description of the issue. Support is available in English, Russian, Italian, Ukrainian, French, Kazakh, and Spanish. Do not send private files, passwords, or pairing codes.

Airelay

Connect both devices to the same Wi-Fi, keep Airelay open, and enter its displayed address in a browser. Enter the current six-digit code. If the code expires, use the new code; five incorrect attempts require a one-minute wait.

If the browser cannot connect, check Local Network permission in Settings, confirm the address, and check that the Wi-Fi network allows devices to communicate. Guest networks, VPN configurations, and firewalls can block local connections.

Files can be up to 2 GiB, subject to free space. If preview is unavailable, download the file and open it in another app. Do not use sensitive files on an untrusted network: HTTP is unencrypted.
